Project Overview
The goal of the Tshiamo Boutique Network Project is to build a dependable, safe, and expandable computer network for the hotel.
Employees will have effective access to shared resources, internet services and communication systems which will link all important departments.
Departments like reception, management, finance, housekeeping, restaurant and administration will be supported by the planned network.
While maintaining the security of the hotels internal systems, it will also give visitors and employees access to wi-fi.
Cisco networking equipment is used in the project, and the primary network architecture is an Extended Star (Tree) topology.
